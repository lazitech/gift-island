# 配乐说明

两条配乐都是代码合成的，不用任何采样或曲库，所以没有版权问题。所有主片版本共用同一条音轨。

## 主片（`film/tools/music.cjs` → `film/assets/music.m4a`）

| 项 | 内容 |
| --- | --- |
| 速度 / 调 | 90 BPM，F 大调；一拍 = 20 帧，所有音符落在十六分音符网格上 |
| 乐器 | 软槌马林巴（基音 + 第 4 泛音 + 短促第 10 泛音 + 毡槌噪声起音，泛音和起音按“亮度”可调）、两层微失谐三角波垫底和弦、小型 Freeverb 混响 |
| 和声 | 每小节一个和弦：Fmaj7 – Dm9 – B♭maj7 – C6/9 – Fmaj7 – Am7 – B♭maj7 – Csus4 – Dm7 – B♭maj9 – F/A – Gm7 – Fmaj7 – Dm9 – B♭maj7 – Am7 – C9sus – B♭maj7/C – F add9 |
| 音画同步 | 音符时间直接读 `film/assets/film-data.js` 里画面用的同一份事件表，不是手对的 |
| 刻意保持安静 | 没有节奏声部；每小节的低音去掉了，只在关键一手和片尾出现；垫底和弦音量减半；混响湿度 0.9 → 0.6；快进时每手只有一个音 |

音符与画面的对应：

| 画面 | 声音 |
| --- | --- |
| 片头「赠岛」每写一笔 | 一个马林巴音，沿 F 大调五声音阶，「赠」上行再回转，「岛」一路走到高点 |
| 4.67 s 字幕出现 | 垫底和弦淡入 |
| 慢放的一手：自己的子 / 送出的子 | 当前和弦里的一个音（偏左）/ 1/4 拍后高一级的音（偏右），两个音连成一个短音型，像一个手势 |
| 快进的一手 | 只有一个轻而暗的音（亮度 0.35、短衰减），沿和弦一级级往上，听起来是一条线而不是一团 |
| 数岛（镜头 3 黑 5 座、镜头 4 白 3 座） | 五声音阶一级级往上走，每座岛一个音 |
| 斜连演示 | D5 → C5 两个轻的下行音 |
| 预览子出现在角落 / 缺口 | 极轻的高音（C6 / A5） |
| 关键一手落下（29.67 s） | 低音 B♭1 + 中音和弦，全片最重的一下 |
| 白方两岛连成一座（30.17 s） | F5–A5–C6 三音慢琶音 |
| 终局空格圆环 | 轻的 C6 |
| 终局数岛 | 黑方左声道、白方右声道各一段柔和的上行音阶 |
| 胜负揭晓 | C9sus 属和弦，下一小节 B♭maj7/C 继续轻轻悬着，陪画面停一小节 |
| 48.0 s 片尾按钮出现 | F add9 大和弦：F1 低音 + 六个音从低到高慢慢滚奏 + 垫底，一直延到片尾淡出 |

测量结果（`music.m4a`，ffmpeg ebur128）：综合响度 **-16.2 LUFS**，响度范围 8.6 LU，真峰值限制在 -1.5 dBTP。
**以上是测量，不是试听**，请亲自听一遍，尤其是 12–14 s 和 35–39 s 两段快进。

重新生成：`cd promo/film && node tools/music.cjs`（需要 ffmpeg）。

## 对比片（`brag-output/work/tools/music.cjs`）

120 BPM，同一个马林巴音色（便于只比较画面风格），加了揭晓后每拍一下的软底鼓、反拍沙锤、每小节正弦低音、
3 → 2 之前的噪声上扬和片尾 F add9 和弦。响度标准化到 -14 LUFS（社交平台常用值）。
