# 配乐说明

两条配乐都是代码合成的，不用任何采样或曲库，所以没有版权问题。所有主片版本共用同一条音轨。

## 主片（`film/tools/music.cjs` → `film/assets/music.m4a`）

| 项 | 内容 |
| --- | --- |
| 速度 / 调 | 90 BPM，F 大调；一拍 = 20 帧，所有音符落在十六分音符网格上 |
| 乐器 | 软槌马林巴（基音 + 第 4 泛音 + 短促第 10 泛音 + 毡槌噪声起音）、两层微失谐三角波垫底和弦、正弦低音、小型 Freeverb 混响 |
| 和声 | 每小节一个和弦：Fmaj7 – Dm9 – B♭maj7 – C6/9 – Fmaj7 – Am7 – B♭maj7 – Csus4 – Dm7 – B♭maj9 – F/A – Gm7 – Fmaj7 – Dm9 – C9sus – F add9 |
| 音画同步 | 音符时间直接读 `film/assets/film-data.js` 里画面用的同一份事件表，不是手对的 |

音符与画面的对应：

| 画面 | 声音 |
| --- | --- |
| 片头「赠岛」每写一笔 | 一个马林巴音，沿 F 大调五声音阶，「赠」上行再回转，「岛」一路走到高点 |
| 4.67 s 字幕出现 | 垫底和弦淡入 |
| 每一手：自己的子落下 | 当前和弦里的一个音（偏左声道） |
| 每一手：送出的子落地 | 同一和弦里高一级的音（偏右声道）；快进时两者都变轻变短 |
| 数岛（黑 5 座、白 3 座） | 五声音阶一级级往上走，每座岛一个音 |
| 预览子出现 / 移到天元 | 极轻的高音（D6 / A5） |
| 关键一手落下（25.33 s） | 低音 B♭1 + 中音和弦，全片最重的一下 |
| 白方两岛连成一座（26.0 s） | A5–C6–F6 上行琶音 |
| 终局空格圆环 | 轻的 E6 |
| 终局双方交替数岛 | 两个八度的上行音阶，左右声道交替 |
| 胜负揭晓 | C9sus 属和弦，悬着等待解决 |
| 片尾字标写出 | 一串快速上行的轻音（滑音） |
| 40.0 s 按钮出现 | F add9 大和弦：F1 低音 + 七个音从低到高滚奏 + 垫底，一直延到片尾淡出 |

测量结果（成片音轨，ffmpeg ebur128）：综合响度 **-16.0 LUFS**，真峰值 **-1.5 dBFS**，响度范围 7.3 LU。
关键时刻（8.0 / 9.33 / 15.33 / 25.33 / 40.0 s）的能量都在对应帧之后陡增，说明音符落在画面事件上。
**以上是测量，不是试听**——请务必亲自听一遍。

重新生成：`cd promo/film && node tools/music.cjs`（需要 ffmpeg）。

## 对比片（`brag-output/work/tools/music.cjs`）

120 BPM，同一个马林巴音色（便于只比较画面风格），加了揭晓后每拍一下的软底鼓、反拍沙锤、每小节正弦低音、
3 → 2 之前的噪声上扬和片尾 F add9 和弦。响度标准化到 -14 LUFS（社交平台常用值）。
